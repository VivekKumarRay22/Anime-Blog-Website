# 🌸 Anime Blog Website

A modern and responsive **Anime Blog Website** built using **Node.js, Express.js, EJS, and Bootstrap**. This project allows users to explore anime-related blog posts through a clean, responsive interface with reusable layouts and server-side rendering.

> This project was built to practice backend development, templating with EJS, routing, and responsive UI design.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/VivekKumarRay22/Anime-Blog-Website.git
```

Navigate into the project

```bash
cd Anime-Blog-Website
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

or

```bash
node app.js
```

Visit

```
http://localhost:3000
```
